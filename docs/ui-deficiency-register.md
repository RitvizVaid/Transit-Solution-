This is an initial bounded source review, not a complete accessibility, security, usability
or field audit. All items are **open**; priorities are proposed, not team commitments.

## Workflow

Pick one bounded ID, inspect the linked code and related feature, agree on behavior and
contract, then implement on a branch. Add focused tests and an acceptance record for
what actually ran. Update both registers with the PR and evidence; keep field and
deployment verification separate. Priority does not imply a feature is assigned or done.
